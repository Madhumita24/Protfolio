# Madhumita — Interactive Portfolio

Public portfolio with cheetah-print heading bands, project filters and dialogs, Pip FAQ companion, and owner-only private notes.

Install with npm install, preview with npm run dev, build with npm run build. D1 migrations are in drizzle/. The owner inbox at /inbox requires ChatGPT sign-in for kolukuluri.m@northeastern.edu.

Configure RESEND_API_KEY and RESEND_FROM as hosted secrets. Question notifications currently go to madhumitakolukuluri24@gmail.com. Public contact remains madhumitakol2402@gmail.com. Never commit .env.local.

Pip answers verified portfolio facts through curated FAQ matching and forwards unknown questions to the private inbox and Resend. Anonymous writes are length-limited, origin-checked, and rate-limited.
